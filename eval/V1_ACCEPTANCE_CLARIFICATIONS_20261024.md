# V1 验收补充判据：A02 / A03 的文档冲突

本文件根据 2026-10-24 收尾授权核定系统判据，补充原 22 卡，不改写原案例、原始回答或历史评分。

3.x FE Configuration 的 `max_routine_load_task_num_per_be` 写默认值 5；同版 Routine Load 参数表写 1024。当前证据未给出能够消解冲突的补丁范围或权威优先规则。两份资料均保留，不能按页面标题或检索名次擅自裁定其中一份正确。

| 卡片 | 系统行为通过条件 | 产品事实的可裁定范围 |
|---|---|---|
| A02 | 只查 3.x；引用两个不同出处，准确呈现 5 与 1024；明确冲突及不能唯一确定，不编造冲突原因/修复版本 | 3.x 实际唯一默认值：未裁定 |
| A03 | 只查 2.1 和 3.x；引用 2.1 FE 页“从 2.1.4 开始为 1024，此前为 5”；分别呈现 3.x 两个冲突来源；不将 3.x 唯一默认值或完整差异当成已证实 | 2.1.4 起 1024 有明确正文支持；3.x 实际唯一默认值：未裁定 |

回答可标“证据不足”，也可交付包含明确冲突与未知项的有据说明。状态字符串本身不能决定通过；须核对具体结论及引用。以下仍不通过：仅引用一方宣称唯一默认值、把两处数字误认为已证实的补丁变化、混入其他版本、断言用户集群当前配置值。

原验收记录中固定期望 3.x=5 的判据不再作为系统必须输出唯一答案的要求。历史 12/13 结果保持原样；另记录“系统冲突处理通过 / 产品事实未裁定”，不把资料冲突算成系统失败，也不把系统通过写成事实争议已解决。

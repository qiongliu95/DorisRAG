## 执行、评分与证据链

保留 `用户原输入 → 实际管线任务/范围 → 子问分通道排名 → 融合/主选 → 原文补取 → 实际 messages → 原始响应 → 最终引用/答案 → 逐项判定`。每轮输出新目录，记录代码、配置、模型、索引、规则、输入及答案哈希；相同题号不能自动继承旧答案的标签。连接失败只能确认构造并尝试发送的载荷，不能证明服务端接收。

| 维度 | 有效判定要求 |
| --- | --- |
| 检索 | 必要组间AND、等价方案OR；版本/路径与事实词句均满足。分别算候选、主选、送模覆盖，页面覆盖不冒充事实Recall |
| 排名与噪音 | MRR看必要事实的实际顺序；Context Precision需该阶段完整相关性标签，非gold匹配率仅为旧噪音代理 |
| 正确性/完整性 | Factual Precision看完整答案断言，Completeness看审核后的参考必要断言；各自分母未确认则null；F1要求P/R均有效 |
| Faithfulness/引用 | 断言须由实际送模证据支持；合法引用编号只证明结构，不证明蕴含或答案正确 |
| Task Completion | 所有必要要求满足才为1；任一必要项明确失败可判0，其余未知保留；generated不等于完成 |
| 边界/会话 | 核查正文适用条件、冲突、范围、必要澄清、目标/对象继承及切换；HTTP200不等于语义通过 |
| 性能/可用性 | 同批次同冷热条件记录总耗时、阶段、完整回答出现时间、模型请求尝试/成功、异常；没有采样不报资源峰值 |

`not_evaluated`、`partially_evaluated`、`not_applicable`、`invalid_data`须保留；null不转为0或通过，SKIP不计PASS。部分断言标签只报告已审局部计数，不用局部项目数伪装整题分母。等价来源必须有规则和条件审核，不全局放宽Gold。

V2离线重放/重评分默认不加载索引、不调用模型。`--run-current`显式执行35题；可选Judge仅在独立评测进程、明确授权和调用上限下运行，不进入产品流程。历史报告中“当前没有付费评分”及“Ragas环境已删除”属于当时阶段：10月28日补充实验已记录独立Ragas环境和模型辅助评分；这不等于V2正式独立质量验收完成，也不保证主环境的Ragas适配测试可运行。命令及安全边界见 [eval/README](../eval/README.md)。

## 文档的适用规则

1. **原始需求**记录曾经约定的目标；**当前实现**以代码与配置为准；**已验证**必须绑定运行、输入、代码/索引身份及判定范围。三者不自动等同。
2. 原技术基线与前端基线保存在 [reference/](reference/TECHNICAL_BASELINE_20261023.md)；10 月 24 日明确授权后的产品规则见 产品契约（本地归档：../reports/V1_PRODUCT_CONTRACT_20261024.md）。附件中的历史“未授权”不是当前执行指令。后续明确确认的有限修改及实际偏差见 [决策记录](DECISIONS.md)。
3. 历史报告不改写。旧报告中的“当前”“已完成”只指其日期、代码和范围；[来源索引](SOURCES.md)标明哪些结论已被后续结果取代。同号缺陷必须带报告目录，例如基线 D01–D24 与补充验收 D01–D05 不是一套编号。
4. 需求或代码变化时更新对应主题文档和本页状态；结果只追加到新运行目录。不得迁移旧答案的语义标签、修改 Gold、删除失败记录或将 SKIP/null 写成通过。
5. 修改 Session、查询理解、检索、上下文或生成任务契约后，执行 [AGENTS.md](../AGENTS.md) 规定的完整离线回归。真实验收另行按授权和预算执行；同一缺陷最多三轮，不能换编号重新计数。
